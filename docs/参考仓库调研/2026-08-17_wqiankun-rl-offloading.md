# Wqiankun/-（计算卸载 RL）— 参考报告

> **调研日期**：2026-08-17
> **仓库**：https://github.com/Wqiankun/-
> **技术栈**：Python + gym + Q-learning + networkx
> **定位**：边缘计算任务卸载决策的学术 toy（Q-learning vs 穷举 vs 随机基线）

## 一、仓库概览

一个强化学习实验：在"本地(用户设备) / 边缘(BS) / 云端"三选一的卸载决策问题上，
用 Q-learning 学最优卸载策略（最小化任务完成时间 + 能量约束），并与穷举法、随机基线对比。
包含 gym 环境（maze_env.py）、Q 表（RL_brain.py）、基线/穷举（baseline.py / brute.py）。

## 二、值得借鉴

**无。** 该仓库是 RL 教学 demo，与三相电流边缘采集/故障诊断没有任何交集：
- 处理对象是抽象任务图（networkx），不是传感器信号
- 决策问题是"任务卸载到哪里"，不是"设备是否健康"
- 无任何信号处理 / 特征提取 / 实时性内容

## 三、不需要借鉴（为什么）

| 点 | 为什么不需要 |
|----|-------------|
| Q-learning 卸载决策 | 我们的"端云分层"如果要做，是算力/带宽工程问题，不是 RL 问题；当前阶段更不需要 |
| gym 环境封装 | 与电流仿真器（物理波形+故障注入）无关 |
| 手写 Q 表（pandas DataFrame） | toy 实现，无工程价值 |

## 四、结论

**借鉴度 ✗ 不相关**，直接跳过。唯一可留意的信息是：它在 GitHub 搜"边缘计算"时出现，
说明**搜"边缘计算"会混入大量学术 demo**，后续调研时应优先过滤关键词
（如加"工业 / 采集 / 网关 / industrial / IoT gateway"）减少噪音。
