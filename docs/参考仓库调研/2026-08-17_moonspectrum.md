## 一、仓库概览

MoonSpectrum 是面向 MoonBit 生态的科学信号处理基础库，聚焦"可复用、可验证、可扩展"的工程基础能力，适用于传感器数据、实验数据、振动信号、周期信号、教学示例和**边缘计算前处理**。当前版本 0.2.2，已发布 Mooncakes 模块。

核心功能（README 核实）：
- **Complex** 复数类型：加减乘、缩放、幅值、近似比较
- **DFT / radix-2 FFT / inverse FFT**；幅度谱、功率谱、频率 bin、**主频检测**
- **STFT、periodogram PSD、单边 PSD、Welch PSD、线性重采样**
- 信号生成：正弦波、方波、脉冲、线性 chirp、确定性白噪声
- 窗函数：Rectangular、Hann、Hamming、Blackman
- 卷积：线性卷积、循环卷积
- 基础滤波：移动平均、FIR taps、**IIR biquad 低通/高通/带通**
- **跨通道相关分析、频谱特征、峰值检测**
- CLI：demo/fft/analyze/window/convolve/stft/psd/resample/biquad/stats/correlate/welch/peaks
- 边界声明：FFT 需 2 的幂；不做音频播放/采集/设备后端；不依赖 native FFI

验证方式：确定性 smoke 测试 + fixture 数值不变量（`docs/fixtures.md`）+ `moon test --target all` + 格式检查。

## 二、值得借鉴（为什么）

### 1. 纯算法层定位（不绑定采集/可视化/平台）
- 借鉴：明确"不绑定具体播放/采集/音频后端，沉淀通用算法层"。
- 为什么：与我们 00-02 模块（仿真/预处理/特征/检测）的定位完全一致——算法层与平台解耦。它的模块划分可作为我们目录组织的对照。

### 2. 算法能力清单交叉核对
- 借鉴：FFT/STFT/PSD(Welch)/IIR/FIR/窗/卷积/相关/重采样/峰值检测/主频检测。
- 为什么：**逐项对照我们的 01_信号预处理 + 02_特征**，可用于核对算法覆盖是否完整（例如：线性卷积、跨通道相关、重采样、峰值检测是否已覆盖）。

### 3. 确定性验证 + fixture 数值不变量
- 借鉴：确定性 smoke 测试 + fixture 构造规则 + 期望数值不变量（`docs/fixtures.md`）。
- 为什么：与我们 06_测试 的"确定性输入 → 期望输出"理念一致，可借鉴 fixture 溯源（构造规则/来源/不变量）的文档化方式。

### 4. 边界明确声明
- 借鉴：明确声明"FFT 需 2 的幂 / 不做流式 IO / 无 native FFI / 不做可视化"。
- 为什么：工程边界清晰，避免 scope 蔓延——对我们规划 M2/M3 边界有参考价值。

## 三、不需要借鉴（为什么）

| 点 | 为什么不需要 |
|----|-------------|
| MoonBit 语言本身 | 我们 Python 栈；代码不能直接用 |
| CLI 工具集 | 我们的验证工具是 Python 脚本（07_测试工具），不同工具链 |
| Mooncakes 发布/生态 | 我们内部项目，不对外发布模块 |

## 四、结论

**借鉴度 ★★★ 高**。它是"纯算法层信号处理库"的干净范例——不绑定平台、边界清晰、验证严格。
对我们的价值主要是**交叉核对 + 组织方式**：① 用它的算法清单核对 01/02 模块覆盖；② 借鉴"算法层与平台解耦 + 确定性验证"的工程组织。
代码语言不同，不直接复用，但方法论完全适用。
