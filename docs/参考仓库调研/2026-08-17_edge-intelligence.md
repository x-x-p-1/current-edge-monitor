# wyc941012/Edge-Intelligence — 参考报告

> **调研日期**：2026-08-17
> **仓库**：https://github.com/wyc941012/Edge-Intelligence
> **技术栈**：Python + PyTorch + socket + pickle
> **定位**：端云协同 CNN 分层推断的学术 demo（树莓派 ↔ PC）

## 一、仓库概览

一个边缘智能/计算卸载的课程项目：在 CIFAR-10 上训练 AlexNet/VGG16，改 forward 支持
**按层粒度**运行，通过 socket + pickle 在"树莓派（移动端）↔ PC（云端）"之间切分推理：

- mobile 端：跑部分层，卸载其余层到云端
- cloud 端：跑剩余层，把中间特征传回
- 卸载决策：硬编码数组 `x=[0,1,0,...]`（0=本地 1=云端）

## 二、值得借鉴（仅概念）

### 1. 端云分层推断的**思路**（不是实现）
- 借鉴点：当边缘算力不足时，把模型拆成"端侧跑浅层 + 云端跑深层"，中间特征传输。
- 为什么（对我们）：RK3588S 上跑大模型/慢路径 MCSA 重算时，可考虑"端侧做轻量特征、
  云端做重诊断"的分层；这是"两阶段板卡策略"（性能盈余 → 测量减法）在算力维度的延伸。

## 三、不需要借鉴（为什么）

| 点 | 为什么不需要 |
|----|-------------|
| socket + pickle 传中间特征 | 无压缩、无安全、无断线处理，工程上不可用；我们上行走 MQTT/时序库 |
| 硬编码卸载决策（x 数组） | toy 级，无自适应决策 |
| 固定 IP / 单线程 accept | 学术 demo 常见粗糙写法 |
| 与电流监测无交集 | 模型对象是图像（CIFAR），不涉及信号处理 |

## 四、结论

**借鉴度 ★ 低**。唯一可取的是"端云分层推断"这个概念性启发，工程实现无可借鉴处。
如果未来要落地端云分层，应参考 FreeIOE/BetterIOT 的 MQTT + 缓存通道，而不是这个 demo。
