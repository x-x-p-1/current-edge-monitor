# freeioe/freeioe — 参考报告

> **调研日期**：2026-08-17
> **仓库**：https://github.com/freeioe/freeioe
> **技术栈**：Lua + skynet（云风服务框架）+ OpenResty(LWF) Web + MQTT
> **定位**：生产级工业物联网边缘计算网关框架（开源，中文社区活跃）

## 一、仓库概览

FreeIOE 是面向工业 IoT 边缘网关的完整运行时框架，跑在 OpenWrt/ARM 设备上。
核心是一个 **skynet 多服务架构**，每个职责一个独立服务：

```
main 启动 → cfg / upgrader / ioe_ext / cloud / appmgr / buffer / ws ...
```

关键能力（从代码中核实）：
- **数据缓冲家族**：`cyclebuffer`（环形）/ `periodbuffer`（周期）/ `filebuffer`（文件）+ 断线缓存、离线>60s 强制冲刷、COV 变化检测（值变化超阈值才上送）
- **云连接**：MQTT v3.1.1/v5 完整实现 + QoS 缓冲 + 断线重连 + 数据/事件/统计分级上送
- **应用管理**：app 打包/上传/安装/卸载/启动，`upgrader` 支持**升级失败自动回滚** + 配置文件 `.bak` 备份
- **扩展包 ext**：gitee/本地仓库拉取扩展，按平台架构动态选版本
- **设备模型**：input/output/command 定义，值带 timestamp + quality
- **硬件自检**：`hwtest`（串口回环、网口 ping、RTC、eMMC、LED、4G 模组）
- **系统信息**：`sysinfo`（平台/架构/SN，SN 由 MAC 地址派生）

## 二、值得借鉴（为什么）

### 1. 数据缓冲 + COV 变化检测 + 离线冲刷 —— 特征日志常存的关键形态
对应 TODO B·M1 剩余「特征日志常存 + 原始默认释放」（数据飞轮）。
- 借鉴：特征日志**不是每帧落盘**，而是「周期批量 + 值变化超 COV 阈值才记 + 离线缓存断线补传」。
- 为什么：我们的看门狗特征每帧产生（~125 帧/s），全量落盘浪费存储且无意义；COV/周期缓冲
  正好匹配"特征常存、原始默认释放"的物理解耦，且磁盘/上行有界（对齐 R7）。

### 2. 升级失败自动回滚 + 配置备份 —— 鲁棒性 R12（重启恢复/OTA）
对应 08 清单 R12「基线/标定 checkpoint，断电重启恢复」与量产 OTA。
- 借鉴：upgrader 把新包解压到临时目录、失败回滚、配置 `.bak` 双备份。
- 为什么：边缘设备一旦 OTA 升级挂掉会失去监护；回滚 + 备份是量产必选项，freeioe 是成熟范本。

### 3. 事件/统计双通道（on_event / on_stat + 事件阈值）
对应我们的触发引擎 + 事件聚合。
- 借鉴：应用层分「数据 / 事件 / 统计」三个独立通道上送，事件带 level，并有 `_set_event_threshold(20)` 限流。
- 为什么：我们触发后的事件/切片需要分级上送与限流，这套通道语义可以直接映射。

### 4. skynet 多服务职责拆分
对应我们未来运行时主循环的模块化。
- 借鉴：cfg / buffer / cloud / appmgr 每个服务单一职责、独立生命周期。
- 为什么：我们 AcquisitionEngine 目前是单体 feed 循环，等接真实硬件后可参照拆分
  （采集 / 缓冲 / 诊断 / 上送 各一进程/线程），便于隔离故障。

### 5. 设备 SN（MAC 派生）+ sysinfo 统一
对应多设备管理与基线"按机台"隔离。
- 借鉴：SN 由硬件 MAC 稳定派生，系统信息统一查询。
- 为什么：将来一台板对应一台电机，基线/标定要按 SN 区分，这是现成方案。

## 三、不需要借鉴（为什么）

| 点 | 为什么不需要 |
|----|-------------|
| Lua + skynet 技术栈 | 我们是 Python 算法栈（numpy/scipy/torch），重写成本极高；只借架构理念不借实现 |
| 私有云平台 / 私有协议绑定 | 自研闭环，不依赖其云平台（ioe.thingsroot.com） |
| OpenResty/LWF Web 管理界面 | 产品化阶段才需要，当前不是重点 |
| 应用商店式 app 热加载生态 | 单板单算法，不需要 app 生态，反而增加复杂度 |

## 四、结论

**借鉴度 ★★★ 高**。最值得抄的两块：
① 缓冲家族 + COV + 离线冲刷（特征日志常存/数据飞轮）；
② 升级回滚 + 配置备份（R12）。两者都是"纯软件、可先行落地"的。
