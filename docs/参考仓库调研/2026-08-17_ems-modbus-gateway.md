# huxinyu190/EMS-Modbus-Gateway- — 参考报告

> **调研日期**：2026-08-17
> **仓库**：https://github.com/huxinyu190/EMS-Modbus-Gateway-
> **技术栈**：Python + pymodbus + MySQL + Web（点位查看器/历史查询）+ 离线包导入导出
> **定位**：储能电站 SCADA 边缘 Modbus 采集与 EMS 上行网关（含 SOH 健康状态计算）
> **契合度**：★★★ 高（VFD/PLC 遥测接入的现成参照）

## 一、仓库概览

基于 Python 的工业 Modbus TCP 数据采集与 EMS 上行网关系统（v2.0，已完成现场部署调试并移交）。支持 PCS 变流器、DSO 配电系统、光伏设备寄存器轮询，**U16/S16/U32/S32/FLOAT32/BOOL 多类型解码**后以 JSON 快照 + 心跳方式上传 EMS 平台。

核心能力（README 核实）：
- 实时寄存器轮询（PCS/DSO/MPPT 点位表，支持 BIT 表）
- **多类型解码**：U16/S16/U32/S32/FLOAT32/BOOL
- JSON 快照 + 心跳上传 EMS
- **1 分钟 / 10 分钟级历史数据入库（MySQL）**
- **SOH 健康状态自动计算**
- 嵌入式 Modbus 写服务（18081 接收器）
- 实时点位 Web 查看器 + 历史数据查询导出
- 离线数据包导入/导出（现场无网环境）
- 地址解码器（点位地址映射工具）

## 二、值得借鉴（为什么）

### 1. 多类型寄存器解码表（VFD/PLC 遥测的现成参照）
- 借鉴：U16/S16/U32/S32/FLOAT32/BOOL 解码 + 地址映射（`地址解码器/` 目录）。
- 为什么：我们将来接 VFD/PLC 遥测（Modbus）必然要做**寄存器→物理量解码**，这套是**完整现场验证过的解码与点位管理方案**。

### 2. SOH 健康状态自动计算
- 借鉴：从采集数据自动计算储能 SOH（健康度）。
- 为什么：与我们要做的「健康度/健康分」指标直接对应——参考它如何从遥测数据定义与计算健康状态。

### 3. 离线包导入导出（现场无网运维）
- 借鉴：离线数据包打包/导入（`导入离线包.bat`/`导出离线包.bat`）。
- 为什么：现场无网场景下的数据搬运方案，与断网续传互补（断网本地缓存 + 人工离线搬运）。

### 4. 历史分级入库 + Web 查询
- 借鉴：1 分钟/10 分钟级历史数据分级入库，实时点位查看器 + 历史查询导出。
- 为什么：对应我们特征日志常存 / 数据飞轮存储架构（freeioe/BetterIOT 之外的第三个落地样例）。

## 三、不需要借鉴（为什么）

| 点 | 为什么不需要 |
|----|-------------|
| EMS 上行协议/平台 | 我们是电流诊断采集器，不依赖储能 EMS 平台 |
| MySQL 存储 | 我们边缘侧用 SQLite（轻量）；MySQL 是云侧/上位机方案 |
| Windows 批处理运维 | 目标平台是 RK3588 Linux |
| SOH 具体公式（储能特有） | 储能 SOC/SOH 与电机健康度不同域，仅参考"定义健康指标"思路 |

## 四、结论

**借鉴度 ★★★ 高**。它是储能电站 SCADA 边缘采集的**完整现场交付**项目，与我们的交集在「Modbus 遥测采集」这一层：
多类型寄存器解码、点位管理、健康状态计算、历史分级入库、离线包搬运。
建议 M1 收尾 / P2 特征规范阶段作为 **VFD/PLC 遥测通道的参照实现**（解码表 + SOH 健康度 + 分级入库）。
