# LGDiMaggio/mcp-motor-current-signature-analysis — 参考报告

> **调研日期**：2026-08-17
> **仓库**：https://github.com/LGDiMaggio/mcp-motor-current-signature-analysis
> **技术栈**：Python 3.10+ + numpy/scipy/pydantic + MCP SDK + MIT（9★，7 releases）
> **定位**：MCP Server 版电机电流特征分析（MCSA）——频谱分析与故障检测的完整 Python 工具链
> **契合度**：★★★ 高（MCSA 领域最直接的可运行参照）

## 一、仓库概览

mcp-server-mcsa 把完整 MCSA 诊断流程做成 MCP Server，让任意 LLM 通过自然语言对电机定子电流做非侵入式频谱分析与故障检测。**这是 MCSA 领域最直接对口的仓库**——把行业标准故障理论做成可运行的 Python 工具链。

**21 个工具**（覆盖我们整个算法栈）：
- 信号加载：CSV/TSV/WAV/NPY 读入（→ `sig_xxxx` ID）
- 电机参数：转差、同步转速、转子频率（铭牌数据）
- 故障频率：**断条 (1±2s)·fs、偏心 fs±k·fr、定子 fs±2k·fr、混合偏心**
- 轴承频率：**BPFO / BPFI / BSF / FTF**（轴承几何计算）
- 预处理：去 DC、归一化、加窗、带通/陷波（= 我们 01 预处理）
- 谱分析：FFT 单边谱、Welch PSD、谱峰检测
- 包络分析：**Hilbert 解调**（机械/轴承故障）
- 时频分析：STFT + 频率跟踪（非平稳工况）
- 故障检测：**自动严重度分级（健康/初期/中度/严重）**
- 一键诊断：`run_full_diagnosis` / `diagnose_from_file` 全流程
- 测试信号生成：合成电流信号 + 可配置故障注入（demo/基准）

**严重度分级阈值（dB below fundamental）**：
| 等级 | 阈值 |
|------|------|
| 健康 | ≤ −50 dB |
| 初期 | −50 ~ −45 dB |
| 中度 | −45 ~ −40 dB |
| 严重 | > −35 dB |

作者注明"通用指导值，应根据具体电机/负载/工况基于基线实测调整"——与我们基线自适应理念一致。

**数据存储**：信号/谱以压缩 `.npz` 持久化到 `~/.mcsa_data/`，用 `sig_xxxx/spec_xxxx` 短 ID 引用，大数组不进对话上下文，重启后数据仍在。

## 二、值得借鉴（为什么）

### 1. 严重度分级阈值（dB below fundamental）
- 借鉴：健康 ≤−50 / 初期 −50~−45 / 中度 −45~−40 / 严重 >−35（边带相对基频的 dB）。
- 为什么：直接可用于我们 M2 健康度分级；且"基线实测调整"理念与我们基线自适应方向一致。

### 2. 完整故障频率公式（理论依据）
- 借鉴：断条 (1±2s)·fs、偏心 fs±k·fr、定子 fs±2k·fr、轴承 fs±k·f_defect（BPFO/BPFI/BSF/FTF）。
- 为什么：正是我们 02 特征 / 03 检测模型要用的 MCSA 边带理论，可直接作为实现依据。

### 3. 数据 ID 引用而非搬运（MCP/API 层设计）
- 借鉴：大数组 `.npz` 落盘，只传短 ID + 紧凑摘要。
- 为什么：我们看板/MCP/API 层可参考"数据引用而非全量传输"模式，避免大数组进上下文/带宽。

### 4. 21 工具模块化划分（API 组织参考）
- 借鉴：加载/参数/频率/预处理/谱/包络/时频/检测/诊断/存储的分层工具。
- 为什么：与我们 00-07 模块划分同构，可作为我们对外 API（M2 决策输出 / 看板）的工具组织参照。

### 5. MCP 接口模式（AI 诊断助手现成样例）
- 借鉴：把 MCSA 诊断暴露成 LLM 可调用工具 + `analyze_motor_current` 引导 prompt + 故障签名 resource 表。
- 为什么：比 IoT-Edge-MCP-Server 更成熟、理论更扎实——我们未来"AI 诊断助手"可直接参考其工具/资源/prompt 三层设计。

## 三、不需要借鉴（为什么）

| 点 | 为什么不需要 |
|----|-------------|
| MCP 协议绑定本身 | 我们若不上 LLM 助手则非必须（Python 栈可直接用） |

| 具体诊断 JSON 报告格式 | 仅参考结构，字段按我们健康度模型定制 |
