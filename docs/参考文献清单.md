## 西门子工程哲学迁移总结

在阅读并消化了数十份西门子官方技术文档后，以下是可迁移到**电流检测领域**的核心工程思想：

| 西门子原设计（振动域） | 电流域迁移映射 |
|------------------------|---------------|
| 加速度传感器 IEPE 接口 | 电流传感器（霍尔/CT）信号调理 |
| 24-bit Delta-Sigma ADC 过采样 | 高精度 ADC + 抗混叠 |
| 带通滤波 10Hz~1kHz（速度） | 带通 45Hz~2.5kHz（工频+谐波+电弧高频） |
| 1kHz~10kHz（加速度 RMS） | 2kHz~10kHz 高频能量比 |
| DKW 自适应基线 | 负载电流健康基线学习 |
| vRMS / aRMS 双指标 | I_rms + 高频电流能量 |
| 频段带能量监控 (Bands) | 电流频谱分频段能量 |
| 希尔伯特包络解调 | 电流包络分析 |
| MonAnL 迟滞防抖 | 电弧报警防抖 |
| 算子下沉硬件 | 预处理+特征在边缘完成 |

> **核心洞察**: 西门子在振动监测领域的"采集下沉硬件，特征上浮软件"的工程哲学，完全适用于电流智能检测。不同之处在于物理域——我们需要关注的是电流的电弧"平肩部"特征、谐波含量 THD、高频能量占比等电气特性，而非机械振动的 BPFO/BPFI 等轴承特征。
