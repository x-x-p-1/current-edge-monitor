## 二、时序约束

| 环节 | 目标延迟 | 说明 |
|------|---------|------|
| ADC 采样 | 每点 ~20μs (50kSPS) | 由硬件 DMA 保证 |
| 滑动窗口积累 | 128/256 点 = 2.56ms / 5.12ms | 窗口大小可配置 |
| 预处理 | < 0.2ms | 纯数值计算，CPU A76 |
| 特征提取 | < 0.5ms | FFT 等可 NEON 加速 |
| NPU 推理 | < 0.5ms | RKNN INT8 量化模型 |
| 后处理决策 | < 0.1ms | 简单阈值逻辑 |
| **端到端总延迟** | **< 4ms ~ 6ms** | 从采样完成到决策输出 |

## 三、窗口管理策略

采用**滑动重叠窗口**保证检测连续性：

```
时间轴 ──────────────────────────────────────────────▶

窗口1:  [████████████████]           (0 ~ 256点)
窗口2:      [████████████████]        (128 ~ 384点, 50%重叠)
窗口3:           [████████████████]   (256 ~ 512点, 50%重叠)
```

- 窗口大小：256 点（可配置）
- 步长：128 点（50% overlap）
- 每 2.56ms 产生一次推理结果

## 四、RK3588S 算力分配

| 处理器 | 任务 | 原因 |
|--------|------|------|
| **A76 大核 #0** | 特征提取 (FFT/小波) | 计算密集型 |
| **A76 大核 #1** | 模型推理调度 + 后处理 | 主控逻辑 |
| **A55 小核** | 预处理 + 数据搬运 | DMA 中断响应 |
| **NPU (6TOPS)** | 模型推理 (CNN/AE) | 专用 AI 加速 |
